# CS · 影视仓最终出链（ceshi）

> 本仓库是「终极兜底」出链层：把 QWJS 分类好的接口 + YSC 的线路合集，
> 整理成 5 个可直接订阅的影视仓链接。每周一 北京时间 03:00 自动更新。

## 五个订阅链接（ghfast 镜像，国内可用）

### ① 直连 · 全部（正常接口）  （255 项）
- 官方：`https://raw.githubusercontent.com/dearloyal/CS/main/1直连-全部.json`
- 镜像：`https://ghfast.top/https://raw.githubusercontent.com/dearloyal/CS/main/1直连-全部.json`

### ② 直连 · 部分（成人接口）  （76 项）
- 官方：`https://raw.githubusercontent.com/dearloyal/CS/main/1直连-部分.json`
- 镜像：`https://ghfast.top/https://raw.githubusercontent.com/dearloyal/CS/main/1直连-部分.json`

### ③ 爬虫 · 全部（正常接口）  （2053 项）
- 官方：`https://raw.githubusercontent.com/dearloyal/CS/main/2爬虫-全部.json`
- 镜像：`https://ghfast.top/https://raw.githubusercontent.com/dearloyal/CS/main/2爬虫-全部.json`

### ④ 爬虫 · 部分（成人接口）  （167 项）
- 官方：`https://raw.githubusercontent.com/dearloyal/CS/main/2爬虫-部分.json`
- 镜像：`https://ghfast.top/https://raw.githubusercontent.com/dearloyal/CS/main/2爬虫-部分.json`

### ⑤ 接口合集（可手动选线路：饭太硬/南风/王二小…）  （2551 项）
- 官方：`https://raw.githubusercontent.com/dearloyal/CS/main/接口合集.json`
- 镜像：`https://ghfast.top/https://raw.githubusercontent.com/dearloyal/CS/main/接口合集.json`

## 备注
- **全部 = 正常可用接口；部分 = 成人接口**（按用户要求命名，不在文件名写“成人”）。
- 直连 / 爬虫 由 QWJS 用直连脚本与爬虫脚本判定后分流。
- 接口合集来自 YSC：导入影视仓后可在线路列表手动切换 饭太硬 / 南风 / 王二小 等。
