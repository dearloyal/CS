# CS · 影视仓最终出链（ceshi）

> 本仓库是「终极兜底」出链层：把 QWJS 分类好的接口 + YSC 的线路合集，
> 整理成 5 个可直接订阅的影视仓链接。每周一自动更新。

## 备注
- 全部 / 部分为接口的不同分组，按使用需要选用。
- 直连 / 爬虫 由 QWJS 用直连脚本与爬虫脚本判定后分流。
- 接口合集来自 YSC：导入影视仓后可在线路列表手动切换 饭太硬 / 南风 / 王二小 等。
